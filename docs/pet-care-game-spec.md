# Spec: เกมเลี้ยงแมวบนหน้าจอ (คัดมาเหมียว)

สถานะ: **ร่าง v0.1** · 5 พ.ย. 2026 · ต่อยอดจากน้องแมวที่เดินบนหน้าเว็บอยู่แล้ว (`assets/pet-cats.js`)

## 1. เป้าหมาย

- ให้คนที่เข้าเว็บได้ "เลี้ยง" น้องแมวของตัวเองจริงจัง ทั้งให้อาหาร ให้น้ำ และให้ยาตอนป่วย
- ถ้าปล่อยทิ้งไว้นานมาก แมวจะตาย มีผลจริงจากการไม่ดูแล
- ทำให้คนกลับมาเว็บบ่อยขึ้น เป็นสาเหตุให้กลับมาดูดีลทุกวัน
- **ไม่รบกวนคนที่แค่มาซื้อของ:** ไม่มี pop-up บังหน้าจอ และคนที่ไม่ได้เล่นต้องไม่เจอแมวตาย

## 2. หลักการสำคัญ

| หลักการ | เหตุผล |
|---|---|
| **เกมเริ่มเมื่อผู้ใช้ "รับเลี้ยง" เท่านั้น** แมวที่เดินเล่นอยู่เดิมยังเป็นแมวประดับ ไม่หิว ไม่ป่วย ไม่ตาย | คนแวะมาซื้อของครั้งเดียวแล้วกลับมาอีกที ต้องไม่เจอแมวตายที่ตัวเองไม่เคยรู้ว่าต้องเลี้ยง |
| **เวลาเดินจริง** ค่าความหิวและอื่นๆ ลดลงแม้ปิดเว็บไป คำนวณย้อนหลังตอนกลับมา | คนรู้สึกว่าแมวมีชีวิตจริง |
| **ตายช้าและมีสัญญาณเตือนหลายขั้น** | ให้โอกาสกลับมาดูแล ไม่ใช่ลงโทษคนที่หายไปแค่วันสองวัน |
| **เก็บในเบราว์เซอร์ (localStorage)** เหมือนตอนนี้ ไม่ต้องสมัครสมาชิก ไม่มีฐานข้อมูลฝั่งเว็บ | ไม่เก็บข้อมูลส่วนบุคคล ทำง่าย ไม่มีค่าใช้จ่าย |
| **ภาษาอ่อนโยน** ใช้คำว่า "ไปดาวแมว" ไม่มีภาพน่ากลัว | เว็บนี้เป็นเว็บร่าเริง |

## 3. ค่าสถานะของแมว (ต่อ 1 ตัว)

ทุกค่าอยู่ในช่วง 0–100

| ค่า | ความหมาย | ลดลงเอง | เพิ่มขึ้นเมื่อ |
|---|---|---|---|
| `food` อิ่ม | 100 = อิ่ม | −100 ใน ~16 ชม. | ให้อาหาร +40 (เกิน 100 = ไม่ยอมกิน) |
| `water` น้ำ | 100 = ไม่กระหาย | −100 ใน ~12 ชม. | ให้น้ำ +50 |
| `health` สุขภาพ | 100 = แข็งแรง | ลดเฉพาะตอนหิว/กระหายหนัก/ป่วย | ฟื้นเองช้าๆ เมื่ออิ่ม มีน้ำ และไม่ป่วย, ให้ยา |
| `mood` อารมณ์ (ไม่บังคับ) | ความสุข | −100 ใน ~2 วัน | เล่น ลูบ ใช้คำสั่งเดิมอย่าง "เล่นกัน" |

สถานะพิเศษ: `sick` (ป่วย: ไม่ป่วย / ป่วย / ป่วยหนัก), `alive` (มีชีวิต / ไปดาวแมวแล้ว), `adoptedAt`, `lastTick`

### อัตราลด (ค่าเริ่มต้น ปรับได้ในโค้ดที่ส่วน `CARE`)

```
food:   −6.25 ต่อชั่วโมง  (16 ชม. จาก 100 ถึง 0)
water:  −8.33 ต่อชั่วโมง  (12 ชม.)
health: −2 ต่อชั่วโมง เมื่อ food หรือ water = 0
        −1 ต่อชั่วโมง เมื่อป่วย, −3 ต่อชั่วโมง เมื่อป่วยหนัก (รวมกันได้)
        +1 ต่อชั่วโมง เมื่อ food > 50, water > 50 และไม่ป่วย
```

## 4. การป่วย

- **โอกาสป่วย:** เช็กทุก 1 ชั่วโมงของเวลาเกม
  - ปกติ 1% ต่อชั่วโมง
  - ถ้า food หรือ water < 20: เพิ่มเป็น 5%
  - ถ้าทั้งสองค่า = 0: เพิ่มเป็น 15%
- **ป่วย → ป่วยหนัก:** ถ้าป่วยแล้วไม่ได้ยาภายใน 24 ชม.
- **อาการให้เห็น:** ขยับช้าลง นอนบ่อย สีซีดลงเล็กน้อย (filter saturate) มีไอคอน 🤒 ลอยเหนือหัว ไม่วิ่งพล่านและไม่ล่าเหยื่อ
- **ให้ยา:**
  - ไอคอนยาจะโผล่ในวงคำสั่ง **เฉพาะตอนป่วย**
  - ป่วย → ให้ยา 1 ครั้งหาย
  - ป่วยหนัก → ต้องให้ยา 2 ครั้ง ห่างกันอย่างน้อย 6 ชม.
  - ให้ยาตอนไม่ป่วย: ปุ่มจะไม่โผล่ (กันกดเล่น)

## 5. การตาย

แมวตายเมื่อ `health` ลดถึง 0 เท่านั้น

ถ้าไม่ดูแลเลยตั้งแต่อิ่มเต็ม 100 จะใช้เวลาประมาณนี้:

| ช่วง | สิ่งที่เกิด |
|---|---|
| 0–12 ชม. | ปกติ ค่อยๆ หิว/กระหาย |
| 12–16 ชม. | น้ำหมด → health เริ่มลด, ไอคอน 💧 กระพริบ |
| ~16 ชม. | อาหารหมด, ไอคอน 🍖, โอกาสป่วยสูง |
| ~1–2 วัน | มักป่วย → ป่วยหนัก, health ลดเร็วขึ้น |
| **~2–3 วัน** | **health = 0 → ไปดาวแมว** |

- **ระดับความยากให้เลือก** ตอนรับเลี้ยง หรือเปลี่ยนทีหลังในสตูดิโอ ทำได้โดยคูณอัตราลดทั้งหมด:
  - **สบายๆ** ×0.5 → ตายใน ~5–6 วัน
  - **ปกติ** ×1 → ~2–3 วัน
  - **ท้าทาย** ×1.5 → ~1.5–2 วัน
- **คำนวณเวลาที่ปิดเว็บไป:** ตอนเปิดเว็บกลับมา ให้จำลองย้อนหลังทีละ 1 ชั่วโมงจาก `lastTick` ถึงตอนนี้ ใช้ค่าสุ่มแบบกำหนด seed จาก id แมว + ชั่วโมง เพื่อให้รีเฟรชซ้ำแล้วได้ผลเดิม
- **ตายแล้ว:**
  - แมวหยุดเดิน มีปีกเล็กๆ ลอยขึ้นช้าๆ แล้วจางหาย
  - แสดงการ์ดเล็กมุมจอ: "น้องส้มไปอยู่ดาวแมวแล้ว 🌟 เลี้ยงมา 9 วัน"
  - ปุ่มบนการ์ด: [รับเลี้ยงตัวใหม่] [ดูความทรงจำ]
  - เก็บไว้ในหน้า "ความทรงจำ" ในสตูดิโอ: ชื่อ สี อายุ วันที่จากไป (ไม่เกิน 20 ตัวล่าสุด)
  - ไม่มีการชุบชีวิต เพื่อให้การดูแลมีความหมาย
- **ไม่ให้ตายต่อหน้าแบบไม่ทันตั้งตัว:**
  - ถ้า health < 20 ตอนเปิดเว็บ ให้ขึ้นแถบเตือนสีชมพูด้านล่าง: "น้องส้มป่วยหนัก ต้องการยาและอาหารด่วน"
  - ถ้าระหว่างที่อยู่บนหน้าเว็บ health ใกล้ 0 ให้หยุดลดที่ 1 จนกว่าผู้ใช้จะออกจากหน้า ไม่ตายต่อหน้าตอนกำลังซื้อของ

## 6. การรับเลี้ยง (เริ่มเกม)

1. ผู้ใช้กดที่แมว → ในวงคำสั่งมีไอคอนใหม่ **"รับเลี้ยง 🏠"** (เฉพาะแมวที่ยังไม่ได้รับเลี้ยง)
2. หน้าต่างเล็ก (drawer เดิมของสตูดิโอ) อธิบายสั้นๆ:
   - "รับเลี้ยงแล้ว น้องจะหิว กระหาย และป่วยได้ ถ้าไม่มาดูแลนานๆ น้องอาจไปดาวแมว"
   - ให้เลือกระดับความยาก
   - ปุ่ม [รับเลี้ยง] [ยังก่อน]
3. รับเลี้ยงแล้ว แมวมีปลอกคอรูปบ้านเล็กๆ และเริ่มนับค่าต่างๆ
4. รับเลี้ยงได้สูงสุด 3 ตัวพร้อมกัน (จากแมวทั้งหมดได้ไม่เกิน 6 ตัวเหมือนเดิม)
5. เลิกเลี้ยงได้ด้วยปุ่ม "ส่งต่อให้บ้านใหม่" แมวกลับเป็นแมวประดับ ไม่นับเป็นการตาย

## 7. หน้าตาและการควบคุม

### 7.1 วงคำสั่ง (กดที่แมว)

เพิ่มไอคอนต่อจากคำสั่งเดิม ใช้สไตล์ไอคอน Lucide ชุดเดิม

| ไอคอน | คำสั่ง | แสดงเมื่อ |
|---|---|---|
| 🍖 ชาม | ให้อาหาร | รับเลี้ยงแล้ว |
| 💧 หยดน้ำ | ให้น้ำ | รับเลี้ยงแล้ว |
| 💊 ยา | ให้ยา | ป่วยเท่านั้น |
| 🏠 บ้าน | รับเลี้ยง | ยังไม่ได้รับเลี้ยง |

- **ให้อาหาร / ให้น้ำ:** ชามเล็กโผล่บนพื้นใกล้แมว แมวเดินไปกินประมาณ 3 วินาที (ใช้เฟรมนั่งเดิม ก้มหัว) แล้วชามจางหายไป
- **อิ่มอยู่แล้ว (> 90):** แมวสะบัดหน้า ขึ้นข้อความ "อิ่มแล้วเหมียว" ไม่เพิ่มค่า
- **ให้ยา:** แมวทำหน้าเบ้ (เฟรม wiggle เดิม) แล้วไอคอน 🤒 หายไป

### 7.2 แถบสถานะ

- **เมื่อแตะแมวที่รับเลี้ยงแล้ว:** แถบเล็ก 3 ขีดใต้ตัวแมว (อาหาร / น้ำ / สุขภาพ) แสดง 4 วินาที
- **ในปุ่ม 🐾 มุมซ้ายล่าง:** มีจุดแดงเมื่อมีแมวต้องการการดูแล คือค่าใดค่าหนึ่ง < 30 หรือกำลังป่วย

### 7.3 ไอคอนลอยเหนือหัว (ความต้องการเร่งด่วน)

- food < 30 → 🍖, water < 30 → 💧, ป่วย → 🤒
- แสดงทีละไอคอนตามลำดับความสำคัญ: ป่วย > น้ำ > อาหาร
- ไม่กระพริบเร็ว ถ้าผู้ใช้ตั้งค่าลดการเคลื่อนไหว (reduced motion) ไม่ต้องแสดงเกมเลย เหมือนแมวตอนนี้

## 8. ข้อมูลที่เก็บ (localStorage `deal-pet-cats` เวอร์ชัน 5)

ต่อแมวแต่ละตัว เพิ่มฟิลด์:

```json
{
  "care": {
    "adoptedAt": 1793900000000,
    "level": "normal",
    "food": 82.5, "water": 64.0, "health": 100, "mood": 70,
    "sick": 0,                    // 0 ไม่ป่วย, 1 ป่วย, 2 ป่วยหนัก
    "sickSince": null, "medsGiven": 0, "lastMedAt": null,
    "lastTick": 1793912345678,
    "stats": { "meals": 12, "drinks": 15, "meds": 1 }
  }
}
```

- รายชื่อแมวที่จากไป เก็บที่ `memorial: [{ name, colors, adoptedAt, diedAt, days }]` ไม่เกิน 20 รายการ
- ย้ายข้อมูลจากเวอร์ชัน 4: แมวทุกตัวไม่มี `care` ก็คือยังไม่ได้รับเลี้ยง ไม่ต้องแปลงอะไร

## 9. ส่วนที่เชื่อมกับเว็บ (ไม่บังคับ ควรทำแบบเบาๆ)

- **หลังให้อาหารครบ 5 ครั้ง:** การ์ดเล็กครั้งเดียว "น้องแมวที่บ้านกินอะไรอยู่? ดูดีลอาหารแมววันนี้ →" ลิงก์ไปหมวดอาหาร แสดงไม่เกินสัปดาห์ละครั้ง
- **ไอคอนยา:** ไม่ลิงก์ไปขายยาจริง เพื่อไม่ให้เข้าใจผิดเรื่องการรักษาแมวจริง ให้มีข้อความเล็กในหน้าความทรงจำ/วิธีเล่นว่า "แมวจริงป่วย ควรพาไปหาสัตวแพทย์"
- ไม่มีการเก็บข้อมูลหรือส่งข้อมูลการเล่นออกจากเครื่องผู้ใช้

## 10. ประสิทธิภาพและคะแนน PageSpeed

- เกมเริ่มทำงานพร้อมแมว คือเมื่อผู้ใช้แตะหรือเลื่อนครั้งแรก หรือ 6 วินาทีหลังโหลด ตามระบบที่มีแล้ว จึงไม่กระทบคะแนน
- การคำนวณย้อนหลังทำครั้งเดียวตอนเริ่ม ต่อจากนั้นอัปเดตทุก 60 วินาที ไม่ใช่ทุกเฟรม
- โค้ดเพิ่มประมาณ 8–12 KB ใน `pet-cats.js` ไม่มีไฟล์ใหม่ ไอคอนเป็น SVG แบบ inline

## 11. เครื่องมือทดสอบ (console)

```js
petCats.care.fastForward(24)   // ข้ามเวลา 24 ชม.
petCats.care.set(0, { food: 5, sick: 1 })
petCats.care.status()          // ตารางค่าของทุกตัว
```

## 12. แผนทำ (แบ่งเป็นขั้น)

| ขั้น | งาน | ผลลัพธ์ |
|---|---|---|
| 1 | รับเลี้ยง + ค่าอาหาร/น้ำ + ให้อาหาร/น้ำ + แถบสถานะ + จุดแดงที่ 🐾 | เล่นได้ ยังไม่มีป่วย/ตาย |
| 2 | ป่วย + ให้ยา + อาการให้เห็น | ครบวงจรดูแล |
| 3 | สุขภาพ + การตาย + การ์ดจากไป + หน้าความทรงจำ + แถบเตือน | ตามที่ขอครบ |
| 4 | ระดับความยาก + ลิงก์ไปดีล (ข้อ 9) + เก็บรายละเอียด | พร้อมใช้งานจริง |

## 13. คำถามที่ต้องตัดสินใจ

1. **เวลาก่อนตาย (ระดับปกติ) ประมาณ 2–3 วัน** เหมาะไหม หรืออยากให้เร็ว/ช้ากว่านี้
2. **ให้เลือกระดับความยากไหม** หรือใช้ระดับเดียวทุกคน
3. **ถึงวันที่ตายแล้วไม่มีการชุบชีวิต** โอเคไหม
4. **ส่วนเชื่อมกับดีล (ข้อ 9)** อยากให้มีไหม
5. **ใส่ "อาบน้ำ / ทำความสะอาดกระบะทราย"** เพิ่มทีหลังไหม เพราะเชื่อมกับหมวดทรายแมวได้ดี
