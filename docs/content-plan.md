# แผนบทความ 30 หัวข้อ — คัดมาเหมียว

เป้าหมาย: **สัปดาห์ละ 2–3 บทความ** → ครบ 30 บทความในประมาณ 3 เดือน

หลักการเรียง:
1. **คำค้นที่คนพร้อมซื้อมาก่อน** (ยี่ห้อไหนดี / เทียบ / ตามงบ) เพราะได้ค่าคอมจริง
2. **คำค้นยาวและเฉพาะ** ติด Google ง่ายกว่าคำสั้น
3. ทุกบทความ **ฝังสินค้า** (`[products:หมวด:4]` หรือ `[compare:รหัส]`) และ **ลิงก์ไปบทความอื่น** อย่างน้อย 2 ลิงก์

> ก่อนเขียน ให้ค้นชื่อหัวข้อใน Google ดูว่าหน้าแรกมีอะไร แล้วเขียนให้**ละเอียดกว่าและมีประสบการณ์จริงมากกว่า**
> ตรวจจำนวนคนค้นจริงได้ที่ Google Keyword Planner (ใช้ฟรี)

```
> ประสบการณ์จริงของเรา (สั้นๆ + รูป)
## วิธีเลือก (3–5 ข้อ)

## เปรียบเทียบ / ข้อดีข้อเสีย
[compare:รหัสจับคู่]
## คำถามที่พบบ่อย (3–5 ข้อ)
## สรุป + ลิงก์ไปบทความที่เกี่ยวข้อง
```

## เช็กลิสต์ก่อนกดเผยแพร่

- [ ] ชื่อบทความมีคำที่คนค้นจริง
- [ ] ย่อหน้าแรกตอบคำถามเลย ไม่เกริ่นยาว
- [ ] มีประสบการณ์หรือรูปจริงของเราอย่างน้อย 1 จุด
- [ ] ฝังสินค้าอย่างน้อย 1 จุด
- [ ] ลิงก์ไปบทความหรือหมวดอื่นของเว็บอย่างน้อย 2 ลิงก์
- [ ] เรื่องสุขภาพแมว: ไม่วินิจฉัยโรค และแนะนำให้ปรึกษาสัตวแพทย์
- [ ] รูปภาพเป็นรูปที่ถ่ายเองหรือมีสิทธิ์ใช้
- [ ] ข้อมูลตัวเลข ราคา และส่วนผสม ตรวจจากแหล่งจริงแล้ว
- [ ] ใช้ AI ช่วยร่างได้ แต่อ่านแก้เองทั้งบทความ

## หลังเผยแพร่ (ทำทุกสัปดาห์ ~20 นาที)

1. ดู **Google Search Console** › Performance ว่าบทความไหนเริ่มมีคนเห็น (Impressions)
2. บทความที่ติดอันดับ 8–20: ปรับให้ละเอียดขึ้น เพื่อดันขึ้นหน้าแรก
3. แชร์บทความใหม่ใน LINE OA / TikTok / ตอบคำถามที่เกี่ยวข้องใน Pantip (ห้ามสแปม)
